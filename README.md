# 森空间 · Mori Space

自用的 Apple 多端照片与文件客户端，集中管理本机照片、群晖 NAS、视频、日历和设备状态。使用 SwiftUI、PhotoKit、EventKit、AVFoundation、Synology 原生接口，没有第三方运行时 SDK，也不通过中转服务器传输照片和文件。

当前版本：**0.27.0（43）**。支持 iPhone / iPad（iOS 17+）和 Mac（macOS 14+，Mac Catalyst）。

## 0.19.2 NAS 网络错误提示

连接失败时区分 DNS 解析、主机连接、超时、网络不可用、TLS 握手与证书校验，并显示系统错误编号。网络不可用时提示核对 App 自己的蜂窝数据／本地网络权限；不会仅凭错误编号就认定权限被拒绝。错误文案不包含系统原始 userInfo、账号、密码、会话或请求 URL。

Safari 能打开同一域名不能单独证明 App 已获得局域网权限。[Apple TN3179](https://developer.apple.com/documentation/technotes/tn3179-understanding-local-network-privacy) 说明 Safari 与 URLSession 的权限要求不同。需要在发生问题的同一设备核对实际地址、权限及错误编号；本版提示改进不代表真实 NAS 连接已恢复。

验证：33 项网络错误与连接回归测试通过，iPhone / Mac Release 构建及签名校验通过。iPhone 当前未连接到开发 Mac，新版尚未覆盖安装到手机。


## 0.17.1 连接等待修复

NAS 手动登录现在显示具体连接阶段，整次操作最多等待 30 秒，并提供「取消连接」。取消、超时或离开连接页后会恢复操作，迟到的登录结果不会覆盖当前连接。登录失败及时显示所在阶段和原因，不再等待额外的注销请求后才结束。保存的账号与已有可用连接在取消时保留；不增加自动密码重试，也不更改 HTTPS 证书校验。

此更新处理连接页面长时间等待的问题。真实 NAS 是否可登录仍取决于设备网络、HTTPS 服务与实际认证结果，不能用模拟接口通过代替真实连接验收。

验证：51 项连接、文件、监控与备份单元测试，以及 3 项 iPhone 界面测试全部通过，涵盖等待中取消、重试、退出和自动恢复。iPhone / Mac Release 构建、主应用及各自小组件签名校验通过；两端已覆盖安装并启动。真实 NAS 登录仍未确认恢复。

## 功能

- **本机照片**：贴边网格、收藏与截图筛选、文件大小、缩放和前后翻页。
- **群晖照片**：接入 Synology Photos，浏览个人／共享空间、文件夹和照片，读取原图。
- **群晖文件**：接入 File Station，目录分页、排序、下载任务及本地导出。
- **Mac 文件浏览**：图标／列表切换、单击选择、双击打开、路径栏、前进后退、右侧信息面板和右键菜单；切换栏目保留当前目录。搜索范围为当前已载入的文件。
- **快速预览**：Mac 使用系统 Quick Look 预览常见图片、文本、PDF 和办公文档；上限 30 MB，关闭后清理临时文件，具体格式以系统支持为准。
- **视频播放**：播放本机能够解码的视频，在线播放要求 NAS 支持分段读取；保存本机播放进度，下次打开可续播。
- **日历**：系统日历的月历与日程列表、当天日程、按日历筛选；使用苹果系统编辑器新建、编辑、删除日程，设置全天、重复、提醒、地点和备注。Mac / iPad 宽屏显示月历与右侧当天日程，iPhone 使用上下布局。
- **桌面小组件**：iPhone / iPad / Mac 提供小号日期、农历与下一项日程，以及中号月历与最多三项近期日程；轻点打开 App 对应日期。
- **纯日历小组件**：中号、大号整月日历，显示每日农历、传统节日并突出今天；离线显示，不需要日历权限。
- **中国放假安排**：内置中国大陆 2025、2026 年官方放假与调休上班日期，在日历和小组件上显示「休」「班」，点日期可查看具体安排。
- **NAS 状态**：CPU、内存、网络、存储和硬盘健康；页面打开且 App 位于前台时每 15 秒刷新。
- **新照片备份**：选择 NAS 目录后备份本机新照片。默认关闭；iOS 后台执行由系统调度，不能保证拍摄后立即上传。

Mac 使用侧边栏与桌面布局；iPhone 使用底部导航，iPad 根据可用宽度调整布局。各端独立保存账号、会话、下载、备份与视频进度，不会自动同步手机和 Mac 的登录信息。

## 使用日历

打开「日历」后点「允许访问日历」，按系统提示授予完整日历访问权限。仅有添加权限时无法显示已有日程。权限被拒绝时可从页面打开系统设置；应用不会在启动时主动弹出日历授权。

点日期查看当天安排，点「＋」新建日程，点已有日程打开系统详情页，再选择编辑或删除。重复事件的修改范围由系统编辑器处理。右上角日历按钮只控制显示，不会删除事件；切换页面保留月份、视图和筛选。

月历默认显示农历：初一显示月份、闰月标明「闰」，春节、元宵、端午、七夕、中元、中秋、重阳、腊八、龙抬头和除夕显示节日名。当日日程与日程列表显示完整农历日期。使用系统中国历离线换算，按当前页面的公历日期对应中国标准时间的农历，不创建额外日程或节日提醒；闰月不重复标注节日。暂不包含节气或农历重复事件规则。

中国大陆放假安排使用国务院办公厅的年度通知：「休」是通知规定的整段放假日期（包含连休、调休日），「班」是明确安排上班的调休日期；普通周末不额外标记。月历、当天详情、日程列表和两类小组件同步显示，不向系统日历写入或订阅事件。日历下方的「中国大陆放假安排」可打开当前年份通知。

目前收录 [2025 年安排（国办发明电〔2024〕12号）](https://www.gov.cn/zhengce/zhengceku/202411/content_6986383.htm) 和 [2026 年安排（国办发明电〔2025〕7号）](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)，于 2026-09-14 核对。数据随 App 离线提供；未收录年份会提示「放假安排未收录」，不会按周末或农历节日推算休班，后续年份需要更新数据并发布新版。这里是全国统一安排，不包含地方、行业、单位的额外假期，也不覆盖港澳台地区的放假规则。

日程保存在所选系统日历账户中，不存到 NAS。选用 iCloud 日历并在各设备开启同一账户的日历后，由系统同步；仅存于本机的日历不会跨设备同步。提醒由系统日历处理，实际通知取决于设备的通知设置。跨设备同步和实际提醒送达需要在已配置账户的设备上验证。

## 添加桌面小组件

在系统小组件库中找到「森空间」，可选择「日历与农历」或「纯日历 · 农历」：

- iPhone / iPad：长按桌面空白处，选择「编辑 → 添加小组件」。
- Mac：右键点桌面空白处，选择「编辑小组件」。Mac 使用内置的原生 WidgetKit 扩展，无需借用 iPhone 小组件。

「纯日历 · 农历」提供中号、大号，不显示日程列表。每一天显示对应农历，初一显示农历月份，节日显示节日名；今天用黄绿色突出。中号空间紧凑时将公历与农历并排，大号上下排列。无需联网、NAS 登录或日历授权，按设备当地日期安排跨午夜更新。点击日期可打开 App；查看或编辑系统日程仍需在 App 内授权。

「日历与农历」需要先打开森空间「日历」并允许完整日历访问，才能显示日程。小号显示日期、农历和下一项日程，点击进入该日程所在日期；没有日程时进入今天。中号显示月历和最多三项近期日程，可以点击日期或日程进入 App。日程遵循 App 中选择显示的日历。

App 打开、回到前台、收到系统日历变更或更改日历筛选时，会更新未来七天的日程摘要。小组件刷新时机由系统调度，不保证即时更新；日期跨午夜及已缓存日程的开始、结束会安排时间线更新。日程摘要超过 24 小时未更新时，「日历与农历」提示打开 App 更新日程。未授权时仍显示日期和农历；纯日历不使用日程摘要。

共享摘要仅包含显示所需的日程标识、标题、时间和颜色，不包含备注、地点或 NAS 登录信息。组件不连接 NAS，也不会修改系统日历。目前仅提供桌面样式，尚未提供锁屏样式。

## 编译运行

1. 安装 Xcode 和对应 SDK。当前代码在 Xcode 27 beta 中编译验证，工程使用 Swift 5 语言模式。
2. 打开 `MoriPhotos.xcodeproj`，选择 `MoriPhotos` scheme。
3. 模拟器选择相应 iPhone / iPad；Mac 选择 **My Mac (Mac Catalyst)**。
4. 真机与 Mac 在 **Signing & Capabilities** 中为主应用和相应小组件 target 选择同一开发团队，再运行。iOS 主应用与扩展都需要启用同一个 App Group，使用自动签名生成包含当前设备的描述文件。

`project.yml` 是工程配置源文件，修改后可通过 XcodeGen 重新生成：

```sh
xcodegen generate
```

Mac 启用了沙盒、网络客户端、照片图库、日历和用户选择文件访问权限；钥匙串访问需要有效的开发签名。个人开发签名并非可通用分发的公证安装包。本仓库不包含证书、描述文件和开发团队配置。


iOS App Group 默认为 `group.dev.kylon.MoriPhotos.calendar`；换用自己的 bundle identifier 时，也需同时修改两份 iOS entitlements 及 `MORI_CALENDAR_APP_GROUP`。Mac 使用 `$(DEVELOPMENT_TEAM).dev.kylon.MoriPhotos.calendar`。模拟器验证主应用与小组件共享日程时应保留默认的本地签名，不要设置 `CODE_SIGNING_ALLOWED=NO`。

## 连接群晖

在 App 连接设置中填写当前设备可访问的 DSM / Photos HTTPS 地址，例如 `https://nas.example.com:5001`，并使用具有相应权限的 DSM 账号登录。

- Synology Photos 和 File Station 分别维护服务会话，支持从钥匙串恢复已保存的连接。
- 使用受信任的 HTTPS 证书；不会跳过证书校验。暂不支持直接输入 QuickConnect ID。
- NAS 监控可能需要更高的 DSM 权限；应用会显示实际接口或权限错误。
- 自动封锁、双重验证及交互式 Secure SignIn 受 NAS 设置影响，不通过反复登录绕过这些限制。

## 测试

在 Xcode 的 Test Navigator 中选择对应测试。测试中的示例账号、令牌、文件内容与 `.invalid` 域名均为合成数据。模拟 NAS 入口仅在指定 DEBUG 测试构建中启用，不包含于正式 Release 包。

日历测试覆盖闰月、夏令时、跨午夜与全天事件边界、权限撤销、乱序查询、筛选恢复，以及真实 EventKit 的保存、单次重复事件编辑与删除。手机界面测试验证系统编辑器创建、重启后读取、日历筛选与页面切换；iPad 和 Mac 验证宽屏布局与月份保留。真实 EventKit 测试只写入隔离模拟器中专用的本机测试日历，不接触个人账户。

小组件测试覆盖摘要过期、事件结束过滤、夏令时时间线、原子缓存读写、权限撤销与并发查询，以及从其他页面和冷启动处理日期链接。系统组件库测试在隔离 iPhone 模拟器运行，保留两种尺寸和添加到桌面的截图供视觉验收。

放假安排测试独立核对两个年份的全部放假、补班日期，并覆盖跨月边界、普通周末、未收录年份和不同时区的页面日期。界面测试核对中秋放假、国庆补班及未收录提示；小组件保留紧凑六行、深色和日程样式截图供检查。


此前已验证目录导航、文件预览与下载和 iPad 导航；本轮补充验证 Mac 监控和目录的宽、窄窗口。尚未逐一验证所有办公格式和真实 NAS 大文件预览。

个人截图和详细本地验收记录不随源码上传。运行界面测试前应使用隔离模拟器；视频测试可通过 `Scripts/PrepareVideoTests.command <SIMULATOR_UDID>` 安装合成视频。
